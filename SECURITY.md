# Security

Please do not report security problems in public Issues. Report them
privately on GitHub:
[Report a vulnerability](https://github.com/Canta360/tekito/security/advisories/new).

Include the TEKITO version, what an attacker could do, and the steps or
code that show it. We reply on the report and credit you in the release
that fixes it, unless you ask us not to.

Supported: the latest release.

---

## セキュリティ（日本語）

セキュリティ上の問題は、公開の Issue ではなく、GitHub の非公開の報告機能から報告してください：[脆弱性を報告する](https://github.com/Canta360/tekito/security/advisories/new)。

TEKITO のバージョン、攻撃者にできること、再現の手順やコードを記載してください。返信はその報告の中で行います。修正したリリースには、希望がない限り、報告者のお名前を記載します。

対象：最新のリリース。
