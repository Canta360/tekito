# Code of Conduct

TEKITO follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([日本語](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/)).

To report a problem, use **Report content** in the menu (…) of the issue,
pull request or comment. The report goes to the maintainers only, and is
kept private.

---

## 行動規範（日本語）

TEKITO は [Contributor Covenant 2.1](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/) に従います。

問題を報告するときは、Issue、プルリクエスト、コメントのメニュー（…）にある **Report content** を使用してください。報告はメンテナーにのみ届き、公開されません。
