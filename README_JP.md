TEKITO は TSF のテキストサービスとして動作する IME で、一般的な Windows アプリでそのまま使用できます。1 つの IME で英語と日本語の両方を入力できます。英語は入力中にスペルが修正され、日本語を追加すると、ローマ字がかなと漢字に変換されます。処理はすべて PC の中で行われます。

> TEKITO はプレビュー版です。動作を確認しているのはメモ帳のみです。そのほかのアプリの状況は[互換性メモ](docs/compatibility.md)にまとめています。

切り替えキーは、日本語キーボードでは半角/全角、US キーボードでは Alt+` です（Ctrl+Space、Ctrl+Shift+Space、なしも選択できます）。**設定 → 一般** で有効にしたモードが、設定した順に切り替わります。日本語キーボードでは、変換キーで日本語、無変換キーで英語、ひらがなキーでひらがな（Shift でカタカナ）に切り替わります。切り替えると、入力位置に新しいモードが一時的に表示されます。

日本語入力は、インストール時に追加するかを選択できます。追加していない場合、または **設定 → 一般** で無効にした場合は、Auto と Direct のみになります。ターミナル、管理者として実行中のアプリ、設定で指定したアプリでは、TEKITO はオフになります。

タスクバーのボタンを右クリックすると、**シークレットモード** も切り替えられます。オンの間は、すべてのアプリで入力内容が学習・保存されません。オフにするまで続き、サインアウトや再起動をするとオフに戻ります。

## 英語の入力

Auto では、普段どおりに入力できます。入力中の単語には下線が付き、その下に候補が表示されます。

| キー | 動作 |
| --- | --- |
| Space | 確実な修正が適用され、スペースが入力されます。続けて押すと、次の候補を選択できます。 |
| Shift+Space | 前の候補に戻ります。 |
| Tab、↑、↓ | 確定せずに候補を移動できます。 |
| Backspace | 修正の直後に押すと、入力したとおりに戻ります。 |
| Esc | 修正されず、入力したとおりになります。 |
| Enter | 候補の選択中はその候補で確定され、それ以外は通常どおり改行されます。 |

次の文字を入力した時点で単語が確定されるため、あとから取り消す操作はありません。辞書にある単語、「brb」のようなチャットの略語、大文字で入力した語、コードと思われる文字列、URL やアドレス、パスワード・数値・メールアドレスの入力欄は修正されません。

Space では、英語の一般的な表記にも修正されます。「i」は「I」に、「dont」「youre」にはアポストロフィが付き、「ofthe」は 2 語に分割され、曜日・月・言語名や「iPhone」のような名前は大文字になります。「cant」「march」のように入力したままでも英単語になる場合はそのまま保持され、もう一方の表記が次の候補に表示されます。スペースを入れずに続けて入力した英語は、確実な場合に自動的に単語に分割され、それ以外は候補に表示されます。

候補には、次に続く単語も表示されます（例：I want t → to）。「the the」のように同じ単語が続くと、Space で 1 つにまとめられます（Backspace で元に戻せます）。**設定 → Auto** では、これらのオン／オフのほか、**Space 2回でピリオド** と **引用符とダッシュを変換** を設定できます。

日付・記号・計算結果も候補に表示されます。「today」「now」で日付と時刻、「heart」「(c)」「->」で ♡・©・→、「1+2=」で 3 です。入力したとおりの表記が第1候補のままなので、選択しない限り変わりません。

![TEKITO の候補一覧。ガラスとシンプル、ライトとダーク。選択中の語の意味を横に表示](docs/images/candidate-list-ja.png)

## 日本語の入力

日本語を追加すると、日本語モードでローマ字を入力できます。入力中は下線付きのひらがなで表示され、Space で全体が文節に分割されて変換されます。もう一度 Space を押すと、選択中の文節の候補一覧が表示されます。

<p align="center">
  <img src="docs/images/japanese-demo-ja.png" alt="「はじめまして」のつもりで「hahimemasite」と入力した例。Space で入力したとおりに変換され、もう一度 Space を押すと候補に「もしかして」付きで「はじめまして」が表示され、横に意味が表示される。続けて「kyouhaiitenkidesune.」が「今日はいい天気ですね。」になる" width="580">
</p>

| キー | 動作 |
| --- | --- |
| Space | 変換されます。変換後は次の候補、Shift+Space で前の候補を選択できます。 |
| ← → | 変換前はカーソルを、変換後は選択する文節を移動できます。 |
| Shift+← → | 選択中の文節を短く・長くできます。 |
| 1〜9 | 候補一覧から選択できます。 |
| Tab、↓ | 入力中に表示される予測候補から選択できます。 |
| Enter | 表示どおりに確定されます。 |
| Esc | 変換後はひらがなに戻り、変換前は入力が取り消されます。 |
| PageUp、PageDown | 候補一覧のページが切り替わります。 |
| F6〜F8 | ひらがな、カタカナ、半角カタカナに変換されます。 |
| F9、F10 | 入力した英字が、全角に、または入力したとおりに変換されます。 |
| Shift+英字 | 英単語の入力が始まります。日本語の途中では、続く英字がそのまま入力されます（NHKの、Windows11）。 |
| 変換 | 未入力のとき、選択した文字（または確定直後の文字）が再変換されます。 |
| Ctrl+Backspace | 確定直後に押すと、確定が取り消され、変換中に戻ります。 |
| Ctrl+Delete | 学習した候補（選択中の予測候補や候補）が削除されます。 |

- **文全体で変換。** 日本語のニュースやウィキペディアの文章から学習した語のつながりと、直前に確定した文をもとに変換されます。さらに小さな言語モデルによって候補の文が比較され、文として自然なものが第1候補になります。
- **AI モデル（任意）。** **設定 → AI** で AI モデルをダウンロードし、有効にできます。有効にすると、日本語の変換結果が AI によって確認されます。AI はこの PC の CPU または GPU で動作し、入力内容が外部に送信されることはありません。軽量（約 250 MB）と高精度（約 1.3 GB）から選択できます。
- **入力ミスの修正。** 隣のキー、抜けや余分なキー、入れ替わった 2 文字などの入力ミスが検出され、意図した語が「もしかして」付きで候補に表示されます。入力したとおりの変換が第1候補のままなので、入力し直す必要はありません。
- **語の意味。** 意味のある候補には本のマークが付き、選択中の候補の意味が候補一覧の横に表示されます。「初め」と「始め」の違いもその場で確認できます。「エモい」「推し活」のような口語にも意味が表示されます。
- **カタカナ語の英語表記。** 外来語や名前には、英語も候補に表示されます（例：ミーティング → meeting、グーグル → Google）。JMdict と日本語版ウィキペディアのデータを使用しています。
- **異体字とアルファベット。** 変換候補に異体字（髙、﨑）が表示されます。アルファベットを読み方で入力できます（ぴーしー → PC）。
- **学習。** 選択した変換が、次回から上位に表示されます。
- **ユーザー辞書。** **設定 → 辞書と学習 → 日本語の単語** で、読みと表記を登録できます。
- **数字・日付・記号。** 数字は数として扱われ、「3こ」は「3個」、「100えん」は「100円」に変換されます。入力した数字は、**設定 → 日本語 → 数字の変換** で設定した形式で変換されます。数字を変換すると、全角・半角や漢数字（千二百三十四）も候補に表示されます。**変換に使う漢字**（教育漢字の学年・常用・人名用）で、使用する漢字を選択できます。「きょう」「いま」で日付と時刻、「やじるし」「ほし」で記号、「にこにこ」で顔文字、「1+2=」で計算結果が表示されます。単漢字は単語のあとに表示されます。
- **郵便番号。** **設定 → 日本語 → 郵便番号から住所に変換** を有効にすると、日本郵便のデータがダウンロードされ、「1000001」を住所に変換できます。
- **ライブ変換。** **設定 → 日本語 → ライブ変換** を有効にすると、入力と同時に変換されます。Space で最後の文節の候補を選択できます。
- **絵文字。** 読みから絵文字も候補に表示されます（例：ねこ → 🐱）。記号のあとに表示されます。
- **ほかの IME との辞書の共有。** Microsoft IME、Google 日本語入力、ATOK からテキストで書き出した単語を、**設定 → 辞書と学習 → 辞書の読み込みと書き出し** で読み込めます。日本語の単語は、ほかの IME で読み込める形式で書き出せます。
- **かな入力とローマ字表。** **かな入力** では、JIS キーボードに印字されたかなを入力できます。**ローマ字表** は編集でき、ほかの IME から読み込むこともできます。
- **多くの入力欄に対応。** スタートメニューの検索、設定アプリ、ストアアプリでも使用できます。フリガナのようなカタカナの入力欄では、カタカナが入力されます。

Microsoft IME、Google 日本語入力、ATOK は各社の商標です。TEKITO が読み込めるファイルを示すためにのみ名前を記載しています。TEKITO は各社と関係ありません。

### まぜ打ちモード

**設定 → 一般** でまぜ打ちを有効にすると、切り替えるモードに追加されます。日本語と英語を、切り替えずに Space で区切って入力できます。`kyouha github ni push suru` は「今日はGitHubにpushする」になります。区切りごとに日本語か英語かが判別され、ローマ字として読めない語（github、push）やよく知られた名前（API）は英語の正しい表記（GitHub）に、日本語は通常どおり変換されます。「take」のようにどちらにも読める語は文脈に合わせて、日本語の文では日本語、英語が続く場合は英語になります。もう一度 Space を押すと、もう一方に切り替わります。

大文字を含む語は、入力中から英字で表示されます。スペースを入れずに続けて入力した英語は、自動的に単語に分割されます。Enter を押すと表示どおりに確定され、入力ミスの修正も保持されます。AI モデルを有効にしている場合は、Enter を押したときに文の表記が自動で選択されます。ライブ変換を有効にすると、英語に続けてスペースを入れずに日本語を入力した場合も、英語と変換後の日本語が区別して表示されます（pushしました）。

## 設定

![TEKITO の設定画面](docs/images/settings-ja.png)

各ページにはよく使う項目が表示され、そのほかの項目はページ末尾の **詳細** にまとめられています。**設定 → 一般 → 入力の見本** では、各モードの入力を短い動画で確認できます。

設定画面、インストーラー、TEKITO のメッセージは日本語と英語に対応しています。通常は Windows の表示言語に合わせて表示され、**設定 → 一般 → 表示言語** で変更できます。

## プライバシー

TEKITO の処理はすべて PC の中で行われます。入力内容が外部に送信されることはなく、アカウントやテレメトリもなく、入力中にネットワークは使用されません。学習した内容は `%LOCALAPPDATA%\TEKITO` に保存され、設定画面から削除できます。ダウンロードが行われるのは、インストール時に日本語を選択した場合の日本語データ、設定で郵便番号を有効にした場合の郵便番号データ、インストール時または設定で AI モデルを選択した場合の AI モデルのみです。詳しくは[プライバシーについて](PRIVACY.md)を参照してください。

## インストール

[Releases](https://github.com/Canta360/tekito/releases) から `TEKITO-0.7.0-full-installer.exe` をダウンロードして実行します。

- **日本語入力を追加する**（Windows の表示言語が日本語の場合はオン）を選択すると、日本語の辞書と言語データ（約 194 MB）が同じリリースからダウンロードされ、チェックサムが照合されてからインストールされます。TEKITO は日本語のキーボード一覧に追加されます。英語は Auto と Direct で入力できるため、英語の一覧には追加されません（**オプション** で追加することもできます）。
- 日本語を選択しない場合は、英語のキーボード一覧に Auto と Direct の TEKITO が追加されます。日本語は、インストーラーを再度実行すると追加できます。
- Microsoft Edge WebView2 Runtime が必要です。Windows 11 には標準で含まれています。
- **AI で変換を見直す** を選択すると、AI モデル（軽量、約 250 MB）もダウンロードされます。インストール後に **設定 → AI** からダウンロードすることもできます。

インストール後、使用するアプリを再起動するか、サインアウトしてサインインし直し、Win+Space で TEKITO を選択します。

インストーラーにはまだコード署名がないため、Windows SmartScreen が実行の確認を求めることがあります。オフラインでのインストール方法は[インストール手順](installer/INSTALL_JP.md)にあります。

## ビルド

Windows 11、C++ デスクトップ開発ワークロード入りの Visual Studio 2026（または 2022）、CMake 3.24 以降、Python 3、設定画面用の Node.js が必要です。

```powershell
cd apps\tekito-settings\ui
npm ci
npm run build
cd ..\..\..
cmake --preset windows-x64-debug
cmake --build --preset windows-x64-debug
.\scripts\verify.ps1
```

`verify.ps1` では、ビルド、テスト、[開発のルール](CONTRIBUTING_JP.md#ルール)の確認がまとめて行われます。自分のビルドを試すときは、管理者 PowerShell で `scripts\register-debug.ps1` を実行して登録し、`unregister-debug.ps1` で登録を解除できます。

言語データは `data/` にあります。大きなパックはリポジトリに含めず、公開元のデータから作成します。

- `scripts\ja\prepare-japanese-packs.ps1` では、Mozc から日本語辞書が、Leipzig のコーパスから語の統計が、TEKITO の slang の一覧と Wiktionary、日本語 WordNet から意味のデータが作成されます。これがないと、日本語はかなまでしか変換されず、漢字に変換できません。
- `scripts\en\prepare-full-data-packs.ps1` では、英語のフレーズ統計が作成されます。なくても TEKITO は動作します。

各パックの出典とライセンスは [Data Packs](docs/data-packs.md) にまとめています。インストーラーを作成するときは、`windows-x64-release` プリセットでビルドし、`installer\package-release.ps1` を実行します。リリースに添付する日本語データの ZIP も一緒に作成されます。

## 構成

| パス | 内容 |
| --- | --- |
| `src/Core` | 英語の候補の検索・順位付けと入力の状態遷移。Windows に依存しません。 |
| `src/Core/Japanese` | ローマ字、かな漢字変換、打ち間違いの候補、予測、意味。Windows に依存しません。 |
| `src/Tsf` | TSF テキストサービスと候補ウィンドウ。 |
| `src/UserData` | 設定、ユーザー辞書、学習データ（SQLite）。 |
| `tests` | エンジンとユーザーデータのテスト（日本語のテスト用データは `tests/data/ja`）。 |
| `eval`、`benchmarks` | 精度と速さをオフラインで測る仕組み。`en` と `ja` に分かれています。 |
| `apps/tekito-settings` | 設定画面。Win32 のホストと WebView2 上の React。 |
| `installer` | セットアップと配布物を作るスクリプト。 |
| `data` | 言語データ。パックごとに manifest と NOTICE があります。英語は `en`、日本語は `ja`、両方で使うものは `common` にあります。 |
| `scripts` | ビルド、インストール、確認のスクリプト。言語ごとのデータを作るものは `en` と `ja` にあります。 |
